从这里到剪映，五步

  1. 锁定类型、做贴图。左边先选这条视频属于哪一类，再选贴图种类、改文字，点「加入素材包」。一条视频要用的贴图都放进来。
  2. 下载素材包。点最下面的「下载素材包 ZIP」，解压成一个文件夹。文件名前面的 01、02… 就是你加入的顺序，可以按脚本顺序排好。
  3. 导入剪映。剪映专业版：媒体 → 本地 → 导入，选中文件夹里的 PNG（手机版：剪辑 → 画中画 → 新增画中画 → 照片）。
  4. 贴到对应的位置。把贴图拖到主轨上方的轨道，对准要强调的那一句，拉长到合适的时长。
  5. 加动画。选中贴图 → 动画 → 入场 / 出场 / 组合，比如「渐显」「向上滑动」「弹入」，再调动画时长。

两种导出方式怎么选：「裁切贴图」只包含贴图本身，适合在剪映里自己摆位置、做放大缩小类动画；「整屏定位」导出 1080×1920 的透明整屏图，拖进剪映就在预览里的位置，不用再挪，适合统一版式。
